# Security Policy

## Supported versions

Security fixes are applied to the latest released version and the `main`
branch. Older releases may not receive backports.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
**Report a vulnerability** flow in the repository Security tab to send a
private advisory to the maintainers.

Include the affected version, environment, reproduction steps, impact, and any
suggested mitigation. Do not include real user data, credentials, or session
content. The maintainers will acknowledge a complete report as soon as
practical, assess severity, and coordinate disclosure and a fix with the
reporter.

AITracker reads local AI-tool data, so issues involving unexpected file access,
secret exposure, unsafe Skill scanning, or privilege-boundary bypasses should
be treated as security reports.
