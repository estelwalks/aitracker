## 背景

本 ADR 是《AITracker 业务模块化与任务编排架构设计》及《AITracker 产品工作台重构实施计划》的 P0 决策门禁。未完成复审前，后续实现必须遵守本文件的保守边界。

## 决策

采用模块化单体；模块只能经 contracts/public API 通信。

## 实施约束

禁止跨模块深层导入；routes 仅作薄适配；platform 不依赖 presentation。

## 代价与放弃

不拆微服务；增加目录与 DTO 样板成本。

## 复审触发条件

当独立部署、团队所有权或扩缩容收益超过分布式成本时复审。

## 状态

草稿。P1 及相关实现开始前必须由产品和技术负责人确认，或在实施计划中登记明确例外。
