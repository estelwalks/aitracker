# ADR-009：统一快照运行时与页面性能读模型

| 属性 | 值 |
|------|-----|
| 状态 | 已接受 |
| 创建日期 | 2026-08-18 |
| 关联 | ADR-002（计划与作业运行时）、ADR-006（架构门禁）、AITracker-页面性能架构设计文档 v1.2 |

## 背景

审计确认页面读取链路存在五类 P1 问题：loader 重型扫描/网络、Dashboard 读模型携带原始事件（约 5.15 MB）、两套权威读取链路、超时不等于取消、browser/server 边界泄漏。本 ADR 记录统一快照运行时与紧凑读模型的落地决策。

## 决策

### 1. 公共运行时策略是唯一人工维护源

`src/app/runtime-policy.source.json` 承载全部产品级新鲜度、刷新周期、超时、网络权限与资源预算；`runtime-policy.schema.ts` 严格校验（未知字段/负值/越界/重复任务/未登记 executor 拒绝）；生成器 `scripts/generate-runtime-policy.mjs` 产出 runtime 投影与任务目录，漂移由 `verify-runtime-policy.mjs` 阻断。`job-catalog.json` 已并入 `scheduledJobs`，不再存在两个可独立修改的周期权威源。

默认周期：汇率 1440、Usage 15、Sessions 30、Skills 60、Installation/WSL/SkillMarket 360 分钟；资源预算 heavy=1 / file=16 / classifier=8。

### 2. 统一快照运行时（Snapshot Runtime）

`src/platform/snapshot-runtime/` 提供：

- `SnapshotEnvelope<T>`：schemaVersion / revision / generatedAt / sourceFingerprint / status / data / diagnostics。
- `SnapshotCoordinator<T>`：单次 hydrate、O(1) `readLatest()`（绝不隐式刷新）、single-flight refresh、abort-before-commit、失败保留 last-known-good、损坏快照回退空态。
- 领域 repository 采用 sibling 文件 + copy-forward（如 Usage 的 `usage-snapshot-envelope.v1.json` 兼容读取旧 `usage-snapshot.v1.json`，旧文件永不覆盖）。

查询路径只读 coordinator；刷新入口统一走任务运行时（`refresh-use-case.ts`）。

### 3. 页面专用紧凑读模型

- `DashboardSummaryReadModel`：四窗口（today/7d/30d/all）服务端预聚合 + 日 buckets + 工具卡片 + 12 个月热力图，**不含原始事件**（10x fixture 下约 90 KB，原 5.15 MB 的 1.7%）。
- `AgentUsageOverviewReadModel`：服务端预构建 ToolOverviewView，`/agents`、`/skills` 不再调用 Dashboard query。
- Widget 采用 revision 协议：≤2 KB status 轮询，revision 变化才取 ≤50 KB model，隐藏暂停。
- 统一 shadow 比对（`shadow-compare.ts`）与 DTO 预算/隐私门禁（`verify-read-model-budgets.mts`）。

### 4. 真实取消与资源预算

- `withTimeout`（abort.ts）组合父信号与超时，区分 user/timeout；Usage 收集器移除 `Promise.race` 假取消，signal 贯穿目录循环与文件解析。
- 可取消 semaphore（`resource-budget.ts`）从策略读取 1/16/8 上限，等待中的 acquire 中止即释放。

### 5. 浏览器/服务器边界

- `verify-browser-server-boundary.mjs` 阻断 browser 图内 `node:*` builtin 与 `*.server.ts` 静态导入。
- 入口 chunk 不再引用任何 server chunk；`verify-bundle-budget.mjs` 实施结构性门禁（server chunk = 0、非字体 CSS 样式 ≤ 40 KB；`@font-face` 字体声明单独计量）。

## 取舍

| 选择 | 代价/缓解 |
|------|-----------|
| 持久化领域快照 | 最终一致；用 stale/last-known-good/更新时间表达 |
| 页面专用 DTO | DTO 数量增加；公共 read-model 契约 + 门禁控制 |
| 后台统一刷新 | 首次可能先见空态；empty/stale 非阻塞触发 |
| 不引入 Redis/数据库 | 数据量大时再评估嵌入式索引 |

## 遗留

- "旧版本 downgrade 发布演练"与"new-default 稳定一个完整正式版本"仍为发布期待办（T7-07 人工演练）。
- 初始共享 JS 含 Recharts/Lucide 共享块的 modulepreload 预取（懒加载 chunk 已独立，不阻塞首屏执行）。
