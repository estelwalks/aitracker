# AITracker Clean Room 开发记录

## 目标

AITracker 采用独立实现；仓库不包含外部 AI 工具采集器的源码、运行时或桥接代码。

## 独立实现原则

1. 先从 AITracker PRD 定义输入、输出和验收标准。
2. 数据采集器按各工具公开或本机可观察的日志格式独立编写。
3. 所有模块使用 AITracker 自有类型、目录划分、缓存格式和错误模型。
4. 不复制参考项目的代码片段后再改名或改写。
5. 任何第三方依赖都必须在发布前完成许可证与来源复核。

## 发布门禁

- [x] 仓库包含 MIT `LICENSE`。
- [x] 仓库包含 `NOTICE`。
- [ ] 依赖许可证清单已生成并复核。
- [ ] 相似度扫描已执行并归档。
- [ ] macOS 与 Windows 安装包第三方声明已核对。
- [ ] 发布负责人完成最终签核。

## 隐私口径

AITracker 的承诺是：不采集、不持久化、不上传对话正文。日志解析可能在本机内存中读取包含 usage 字段的完整记录，但只提取 Token、模型、来源、项目、会话标识和时间等统计字段。
