## 1. 背景与目标

以 `docs/V3.0_TrustTools/project-sparkle-hub-92-main` 的最新原型为视觉与信息架构参照，重构 TrustTools 的整体应用界面，并升级首页总览与工具概览（现有 `/skills`）的真实数据展示和操作体验。

原型中的静态 Mock 仅用于设计参考。现有本地用量、定价、会话、工具扫描、安全评估等模块仍是权威数据来源，禁止以伪造指标替换。

## 2. 功能范围

### 2.1 核心功能

1. 统一应用壳、设计令牌、面板、指标卡、筛选与表格的终端化视觉语言；保留 i18n、主题、有效路由与响应式行为。
2. 首页提供按统一统计区间过滤的 KPI、趋势、来源/模型/项目拆分、热力图、明细与安全导出。
3. 首页以真实会话数据补充会话数、时长、轮次与编辑轮次；无数据时明确显示不可用，绝不估算伪造。
4. 工具概览提供真实工具资产的扫描时间、安装覆盖、来源、版本、更新时间、最后使用、更新状态和既有安装/同步/卸载/黑名单能力。
5. 所有 UI 数据均经模块自己的 query/application 合约投影，不泄露路径、技能内容或其他敏感扫描细节。

### 2.2 本次不做

- 原型固定月预算、模拟调用数/日均调用数、虚构蒸馏进度。
- 在没有稳定 `skillId → assessment` 证据关系前，为工具列表捏造安全结论。
- 迁移原型已废弃的 `/chats` 路由；应用继续使用现有 `/sessions`。

## 3. 数据需求

| 页面 | 维度 | 权威来源 | 获取方式 |
|------|------|----------|----------|
| 首页 | Token、来源、模型、项目、时间 | LocalUsageSnapshot | dashboard server query / application 聚合 |
| 首页 | 已知、估算、未知费用及缓存节省 | PricingSnapshot + usage events | pricing adapter；状态显式展示 |
| 首页 | 会话数、时长、轮次、编辑轮次 | SessionRecord | sessions 公共 query / dashboard adapter |
| 首页 | Skill 数及安装覆盖 | SkillSnapshot | skill-catalog browser-safe 投影 |
| 工具概览 | 名称、描述、最后使用、安装位置 | SkillSnapshot | skill-catalog query facade |
| 工具概览 | 版本、来源、更新状态/理由 | SkillInstallation | 仅投影安全 DTO 和 opaque installationRef |

## 4. 验收标准

1. 1440px、1024px 与窄视口下页面无重叠；KPI 和宽表格可横向滚动。
2. 日期区间变化后 KPI、趋势、拆分、热力图、明细与导出使用同一组过滤事件。
3. 费用数据始终区分已知、估算、未知；空数据保持 onboarding/空状态。
4. 工具页筛选、排序、分页、批量操作、同步冲突与卸载确认沿用真实后端操作，刷新不使用 Mock/Toast 代替扫描。
5. 新增文本完整进入四语言消息目录；关键 DTO 与模块边界验证通过。

## 5. 风险与依赖

- 月预算与全局安全结论没有现有权威模型，本次不展示伪指标。
- 会话与用量数据可能来自不同采集周期，需在 read model 中暴露可用性与生成时间。
- 原型目录为用户提供的未追踪参考材料，严禁将其纳入构建或提交。
