## 1. 背景与目标

本次迭代以 `docs/V3.0_TrustTools/project-sparkle-hub-92-33a292ea-main`（以下简称“原型”）及其运行页面为视觉、导航与交互参考。主应用必须保持该原型的信息架构和页面风格，同时继续使用主应用已存在的本地扫描、价格计算、原子持久化及安全扫描能力。

原型目录为只读参考资产；不得对其中任一文件做写操作。原型中的示例数值、`mock-data` 和演示性流程不是主应用的数据源。

## 2. 功能范围

### 2.1 必须实现

| 编号  | 需求                   | 验收标准                                                                                                                                                                             |
| ----- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| PA-01 | 应用框架和菜单对齐     | 侧栏分组、菜单顺序、图标语义、搜索栏、状态徽标、设置/收起入口与原型一致；深链接页面不强行加入侧栏。                                                                                  |
| PA-02 | 全部原型路由可访问     | `/`、`/agents`、`/distill`、`/reports`、`/security`、`/tracker`、`/skills`、`/settings`、`/sources`、`/chats`、`/chats/$id` 均可渲染，不出现 404。                                   |
| PA-03 | 首页视觉与真实数据兼容 | 保留原型的洞察、监听、4 张状态卡、区间栏、指标、工具筛选、趋势、模型、项目、日历和上下文区块；所有数字来自本地采集/计算。无数据或无价格时展示明确的空/不可用状态，不用示例数字填充。 |
| PA-04 | 原型页面视觉对齐       | 工具、蒸馏、简报、安全、燃烧榜、Skill、设置、数据来源页面的层级、卡片、工具栏、表格、空态与主要操作与原型一致，且保留当前业务功能。                                                  |
| PA-05 | 会话页面补齐           | 以现有会话扫描与恢复模块的公开投影驱动会话列表与详情；支持真实筛选、分页、状态显示、进入详情和可恢复会话的恢复操作。私有文件路径、命令和会话内容不得泄露到浏览器。                   |
| PA-06 | 非 mock 数据约束       | 任何生产展示值必须来自本地日志、扫描、持久化记录、用户输入或明示为“不可用”的计算结果；禁止从原型复制演示数组、固定 KPI、随机数或伪造时间线。                                         |
| PA-07 | 交互可用性             | 现有扫描、刷新、安装、删除、生成、编辑、导出与设置操作继续调用真实服务端函数/桌面 IPC；加载、失败、空态与成功反馈可见。                                                              |
| PA-08 | 多轮验证               | 对每条路由执行浏览器可达性与导航检查；重点交互执行端到端验证；变更后至少进行一次视觉回归、一次类型检查、一次 lint、一次单元测试和一次生产构建。                                      |

### 2.2 范围外

- 改动原型目录、把原型转为运行时依赖或复制其 mock 数据。
- 以外部云端数据取代用户本地数据，或在未获得授权时上传本地日志。
- 改写用户已经存在的未提交改动。

## 3. 数据需求

| 页面/能力              | 权威数据源                                           | 数据类别       | 无数据策略                                 |
| ---------------------- | ---------------------------------------------------- | -------------- | ------------------------------------------ |
| 首页、燃烧榜、数据来源 | `local-usage` 扫描器、价格目录、dashboard 查询模型   | 原始/计算      | 显示 0、空表或“不可用”，附真实原因。       |
| 工具与 Skill           | 本地 Skill 扫描器、工具注册表、Skill 市场适配器      | 原始/持久化    | 展示扫描结果和可重试空态。                 |
| 安全                   | 本地静态扫描器、规则库、原子检测历史                 | 原始/衍生      | 显示尚未扫描，不生成风险结论。             |
| 蒸馏、简报             | 会话扫描器、蒸馏候选与报告原子存储                   | 原始/手动/衍生 | 空态引导真实操作。                         |
| 会话与恢复             | `sessions` 模块、`local-sessions` 扫描器、恢复适配器 | 原始/衍生      | 显示未发现本地会话；恢复不可用时解释原因。 |
| 设置                   | 设置服务、桌面 IPC、浏览器本地偏好镜像               | 手动/持久化    | 保留可用默认值并说明持久化范围。           |

## 4. 页面与菜单矩阵

| 原型路由     | 侧栏入口   | 主应用目标            | 关键真实操作                  |
| ------------ | ---------- | --------------------- | ----------------------------- |
| `/`          | 首页总览   | 数据大盘              | 区间、工具筛选、AI 洞察刷新。 |
| `/agents`    | 工具概览   | 工具与本地 Skill 总览 | 扫描、查看工具状态。          |
| `/distill`   | 蒸馏工作台 | 知识蒸馏              | 选择会话、生成、审批、安装。  |
| `/reports`   | 简报与记忆 | 报告与记忆            | 生成、编辑、保存、导出。      |
| `/security`  | 安全与防御 | 静态安全扫描          | 选择目标、扫描、查看历史。    |
| `/tracker`   | 燃烧榜     | 用量分析              | 真实维度筛选与下钻。          |
| `/skills`    | Skill 管理 | 本地 Skill/市场       | 扫描、安装、删除、查看详情。  |
| `/settings`  | 设置       | 偏好与运行时配置      | 保存偏好、语言/货币切换。     |
| `/sources`   | 深链接     | 数据来源              | 刷新并查看采集状态。          |
| `/chats`     | 深链接     | 会话管理              | 查询、筛选、进入详情、恢复。  |
| `/chats/$id` | 深链接     | 会话详情              | 查看安全公开摘要并恢复。      |

## 5. 非功能需求与风险

- 浏览器可见层只能接收会话公开投影；绝不传递原始路径、恢复命令、密钥或会话全文。
- 本地扫描可能慢或无权限；页面必须有加载、超时和错误状态，不可阻塞整个应用框架。
- 用户工作区已有未提交测试与探针文件；本迭代只提交明确归属的文件。
- 视觉验收以布局、组件层级、菜单信息架构和交互状态为准，不要求演示数据与真实数据数值相同。
