## 背景

本 ADR 是《TrustTools 业务模块化与任务编排架构设计》及《TrustTools 产品工作台重构实施计划》的 P0 决策门禁。未完成复审前，后续实现必须遵守本文件的保守边界。

## 决策

以 JobType、Schedule、JobRun 取代页面 timer 和仅刷新型任务。

## 实施约束

JobType 随包 JSON；Schedule 是受控用户状态；JobRun 持久化、single-flight、可恢复、可取消。

## 代价与放弃

应用退出后不执行；不支持用户定义任意命令或 cron。

## 复审触发条件

需要宿主级定时、工作流 DAG 或多实例时复审。

## 状态

草稿。P1 及相关实现开始前必须由产品和技术负责人确认，或在实施计划中登记明确例外。
