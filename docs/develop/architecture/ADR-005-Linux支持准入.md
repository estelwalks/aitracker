## 背景

本 ADR 是《TrustTools 业务模块化与任务编排架构设计》及《TrustTools 产品工作台重构实施计划》的 P0 决策门禁。未完成复审前，后续实现必须遵守本文件的保守边界。

## 决策

Linux 保持 planned，采用 XDG 路径抽象但不自动扫描或安装。

## 实施约束

升级 supported 前必须具备真实 fixture、Reader 验证、打包 smoke 和任务恢复证据。

## 代价与放弃

延后 Linux 用户可用性。

## 复审触发条件

四项准入证据均通过且发布渠道可用时复审。

## 状态

草稿。P1 及相关实现开始前必须由产品和技术负责人确认，或在实施计划中登记明确例外。
