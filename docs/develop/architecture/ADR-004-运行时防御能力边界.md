## 背景

本 ADR 是《AITracker 业务模块化与任务编排架构设计》及《AITracker 产品工作台重构实施计划》的 P0 决策门禁。未完成复审前，后续实现必须遵守本文件的保守边界。

## 决策

静态评估与运行时观察拆分；没有授权事件源时只提供观察/告警。

## 实施约束

security-assessment 拥有 Finding；security-monitor 拥有 Observation/Incident；阻断能力需显式授权。

## 代价与放弃

首期不能阻止外部 Agent 的任意行为。

## 复审触发条件

引入可信 Hook、代理或 OS 事件源时复审阻断策略。

## 状态

草稿。P1 及相关实现开始前必须由产品和技术负责人确认，或在实施计划中登记明确例外。
