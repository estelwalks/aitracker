# AITracker 用户手册

AITracker 是一个本地优先的 AI 工作台，用来统一查看本机 AI 工具的使用情况，并将会话沉淀为记忆、Skill 和工作流。

## 开始使用

首次打开后，AITracker 会读取电脑中已安装 AI 工具的本地记录，并建立用量索引。首次扫描可能需要一点时间。

建议先完成：

1. 打开左侧「设置」。
2. 进入「模型配置」。
3. 添加 AI 模型的接口地址、模型名称和 API Key。
4. 点击测试并保存。

没有配置模型也可以查看本地用量、规则洞察和历史数据，但 AI 增强、蒸馏和智能报告会提示配置模型。

## 首页总览

首页展示：

- Token 消耗和费用估算
- 今日会话数量
- 缓存命中率
- Agent 覆盖情况
- 安全状态
- 蒸馏资产和报告数量

时间范围可以切换为今天、近 7 天、近 30 天或全部。

## Agent 概览

进入「Agent 概览」可以查看不同 AI 工具的用量和活动情况，包括 Codex、Claude Code、Cursor、Gemini CLI 等。

点击具体 Agent 可以查看：

- Token 消耗
- 会话次数
- Skill 覆盖
- 安全状态
- 消耗趋势

AITracker 只读取本机可识别的结构化用量数据，不会把完整对话内容展示到用量统计中。

## 今日洞察

今日洞察会根据当前数据给出简短结论，例如安全风险、用量变化和 Agent 活跃情况。

没有可用 AI 模型时，洞察会使用本地规则生成。如果需要更深入的关联分析和智能化处置建议，点击洞察卡上的：

> ✨ 接入 AI 模型，解锁深度数据分析与智能化处置建议 ｜ 立即接入

按钮会直接打开模型配置页面。

## 蒸馏工作台

蒸馏可以把选中的会话内容整理成结构化资产。

### 操作步骤

1. 进入「蒸馏工作台」。
2. 选择需要分析的会话或项目。
3. 选择蒸馏模式：快速模式或高级模式。
4. 选择产物类型。
5. 点击「开始蒸馏」。

支持的产物包括：

- 记忆
- Persona
- Skill
- 工作流/Brief
- Prompt

高级模式可以进一步选择具体会话片段，并补充提示词。

### 蒸馏进度

蒸馏任务会在后台运行。最小化窗口、切换页面或暂时离开应用，都不会中断任务。重新进入蒸馏页面后会恢复进度。

进度会经历读取素材、生成、质量检查、保存和同步等阶段。最终完成由服务端结果确认，不会提前显示完成。

### 没有配置模型

如果没有配置 AI 模型，点击蒸馏按钮会显示配置提示，并提供进入「设置 → 模型配置」的入口，不会出现点击后无反应的情况。

### 蒸馏历史

蒸馏历史支持：

- 勾选单条记录后删除
- 勾选多条记录后批量删除
- 当前页全选或取消全选

删除会同步移除本机保存的候选记录及其关联信息。

## 记忆与 Skill

蒸馏完成并同步后，可以在「记忆」中查看沉淀内容；Skill 类型的产物可以保存到对应 Agent 的 Skill 目录。

保存前建议检查：

- 标题是否准确
- 内容是否包含敏感信息
- 目标 Agent 是否正确
- 生成内容是否需要人工修改

## 日报与周报

进入「日报周报」可以查看和生成日、周周期报告。

- 可以切换日报和周报。
- 可以查看历史归档。
- 生成后可以预览和编辑。
- 没有模型时会生成本地规则草稿，并提示当前为本地结果。
- 配置模型后可以使用 AI 增强报告内容。

## 安全检测

安全检测用于检查本机 Skill 文件和相关风险。

- 基础规则检测在本机执行。
- 需要 AI 深度分析时使用已配置模型。
- 可以查看风险项、扫描进度和扫描历史。
- 扫描过程中可以通过桌面顶部动态栏查看状态。

## 桌面组件和顶部动态栏

桌面客户端支持系统托盘和顶部动态栏。

- 动态栏显示实时用量、安全状态和任务进度。
- 鼠标悬停或点击可以查看组件卡片。
- 蒸馏和安全检测进行时，可以查看任务状态。
- 可以在「设置 → 通用」中开启或关闭顶部动态栏。
- 关闭窗口通常会隐藏到托盘；需要完全退出时，请从托盘菜单选择「退出」。

## 数据和隐私

AITracker 默认在本机运行：

- 本地会话和用量数据保存在当前设备。
- 用量统计主要读取 Token、模型、时间、来源和项目等信息。
- 原始 prompt 和完整回复不会作为用量统计返回。
- 蒸馏时只使用用户选择的会话素材。
- API Key 不应分享、提交到代码仓库或放入截图。
- 使用远程模型时，发送内容取决于具体功能和用户选择，请同时查看模型服务商的隐私政策。

## 常见问题

### 为什么 AI 增强不可用？

请进入「设置 → 模型配置」，检查模型、接口地址和 API Key 是否完整，并使用测试功能验证连接。

### 为什么蒸馏按钮无法开始？

没有配置模型时，点击按钮会显示配置引导。配置完成后重新返回蒸馏工作台即可。

### 切换页面后蒸馏进度不见了怎么办？

任务仍在后台运行。重新进入蒸馏工作台即可恢复进度显示。

### 如何彻底退出应用？

点击系统托盘中的 AITracker 图标，在菜单中选择「退出」。
