## Epic: 模块化 UI 与核心概览重构

### Story UI-01: 全局设计系统与应用壳

**工作量**: 3 人日  
**验收标准**: 统一原型视觉语言，保留 i18n、主题、有效导航与响应式侧栏。

- [ ] T-UI-01：重构设计令牌、通用 panel/metric/toolbar 视觉规范。
- [ ] T-UI-02：升级 AppShell，消除硬编码状态并保持现有路由。

### Story DASH-01: 首页总览的真实数据与交互

**工作量**: 5 人日  
**验收标准**: 统一统计区间驱动 KPI、趋势、拆分、明细和导出；不使用 Mock 指标。

- [ ] T-DASH-01：实现 dashboard renderer-safe read model 与数据可用性投影。
- [ ] T-DASH-02：重构首页工具栏、KPI rail、趋势/拆分/热力图/明细布局。
- [ ] T-DASH-03：补充真实会话指标与空/降级状态。

### Story TOOLS-01: 工具概览与资产治理

**工作量**: 5 人日  
**验收标准**: 工具页从真实扫描 DTO 构建概览、筛选、排序与分页，所有治理操作保留明确确认。

- [ ] T-TOOLS-01：建立 skill-catalog renderer-safe summary/facet/item view model。
- [ ] T-TOOLS-02：重构工具页页头、筛选器、列表与详情展示。
- [ ] T-TOOLS-03：接入真实刷新与保留安装、同步、卸载、黑名单交互。
