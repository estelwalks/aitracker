## 1. 请求摘要

打造**个人 AI 主权**桌面工具。把散落在各 AI 工具的 skills、token 消耗、会话记录，统一收回用户手里。参考 TokenTracker 的开源思路，叠加 TrustTools 自有能力（安全检测、Skill 市场对接、海报分享、会话恢复）。

## 2. 业务目标

### 主要目标

1. **Token 用量透明化**：让用户看见 token 消耗和费用，打开即见首页大盘，按时间/Provider 下钻
2. **Skill 资产管理**：扫描本地 skill、数量统计、一键清理、一键同步到多个 AI 工具
3. **Skill 安全检测**：外部下载的 skill 拖进来，静态规则扫描，几秒出安全报告
4. **TrustTools Skill 同步**：打通 Web 端 Skill 库，桌面版直接搜索/下载/安装
5. **会话恢复**：扫描本地 AI 工具的会话记录，检测丢失或异常中断的会话，支持一键恢复

### 成功信号

- 安装后 2 分钟内看到自己的 token 消耗
- 覆盖 27 个 AI 工具的 token 解析（Claude Code、Codex CLI、Cursor、Kiro、Gemini CLI、OpenCode、OpenClaw、Every Code、Hermes Agent、GitHub Copilot、Kimi Code、oh-my-pi、CodeBuddy、WorkBuddy、Grok Build、Kilo CLI、Kilo Code、Antigravity、pi、Craft Agents、Roo Code、Zed Agent、Goose、Droid、Mimo Code、ZCode、AnythingLLM Desktop）
- 外部 skill → 拖入检测 → 出报告 < 30 秒
- 桌面版搜索 → 选中 → 安装到指定 agent < 15 秒
- 启动后自动扫描并发现可恢复会话 < 10 秒

### 失败后果

- 覆盖面窄，沦为小众工具
- 隐私策略不当导致用户不信任
- 各模块割裂，体验不统一

### 明确的非目标

- 不是另一个 AI 聊天客户端或 agent
- 不读取/存储用户完整对话内容（仅提取 token 统计元数据）
- 不替代任何现有 AI 工具，而是作为它们之上的"数据主权层"

## 4. 角色与关键场景

### 目标用户

| 角色      | 描述                                  | 优先级 |
| ------- | ----------------------------------- | --- |
| 个人开发者   | 日常使用 3-5 种 AI 编码工具，装了 10-30 个 skill | P0  |
| AI 重度用户 | Web + CLI + IDE 多端使用 AI，skill 来源分散  | P0  |

### 核心场景

**场景 1：首次使用**

1. 下载 .dmg 双击安装
2. 自动检测本地已安装的 AI 工具
3. 打开即见首页大盘，Token 消耗、费用一目了然
4. 未检测到 AI 工具时展示空状态引导页
5. 扫描本地 skill 目录，查看统计

**场景 2：Skill 安全检查**

1. 从论坛/群里下载了 skill
2. 拖进客户端安全检测页
3. 静态规则扫描，几秒出安全报告
4. 安全的 → 放心安装；可疑的 → 用户根据风险项自行判断

**场景 3：从 TrustTools 市场安装 Skill**

1. 在桌面版搜索关键词
2. 浏览返回的 Skill 列表
3. 选中 Skill → 选择安装到指定 agent（3 选 1）
4. 自动下载 + 安装，提示完成

**场景 4：会话恢复**

1. 某次对话异常中断或工具崩溃，担心会话丢失
2. 打开 TrustTools 切换到「会话恢复」Tab
3. 自动扫描展示各 AI 工具中丢失的会话列表
4. 选中会话 → 一键恢复，在原工具中重新打开

**场景 5：消耗海报分享**

1. Dashboard 点「生成海报」
2. 选时间范围（今日/本周/本月）
3. 预览海报 → 保存本地或复制到剪贴板

### 边缘场景

- 用户没有任何 AI 工具（空状态引导）
- 用户离线（本地功能正常，Skill 市场不可用时提示"网络不可用"）
- 用户选了未安装的 agent 作为安装目标（提示并引导安装）
- 安全检测次数用完（提示"今日次数已用完，请明天再试"→ 0:00 自动重置）
- 未扫描到任何可恢复的会话（提示"未发现丢失会话"）

## 5. 非功能需求

| 维度             | 需求                                                   | 依据      |
| -------------- | ---------------------------------------------------- | ------- |
| **数据本地化**      | 所有数据存储本地，不上报任何云端                                     | 隐私优先    |
| **启动速度**       | 安装到首次看到数据 < 2 分钟                                     | 用户体验基线  |
| **仪表盘响应**      | 页面加载 < 2 秒，图表渲染 < 1 秒                                | 用户体验基线  |
| **内存占用**       | 后台进程 < 200MB                                         | 常驻不影响工作 |
| **兼容性**        | macOS 13+ (Apple Silicon + Intel)；Windows 后续版本补充        | 先聚焦 macOS |
| **安全与隐私**      | 所有数据本地处理，不上传远端；会话恢复仅扫描本地文件，需用户授权                     | 隐私红线    |
| **无账号**        | 不需要登录注册，安装即用                                         | 极简上手    |
| **Clean Room** | 架构可借鉴 TokenTracker，代码自研                               | 合规      |
| **中文界面**       | 中文界面（后续版本补充英文）；数据标签（模型名/Provider名）保留原文               | 中文用户为主  |
| **换肤**         | 暗色/亮色 2 套主题，支持一键切换                                   | 个性化     |
| **海报设计感**      | 消耗海报 1 套视觉模板，1080×1920 竖版 PNG，带品牌标识                  | 社交传播    |
