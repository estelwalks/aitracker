## 1. 请求摘要

打造**个人 AI 主权**桌面工具。把散落在各 AI 工具的 skills、token 消耗、记忆，统一收回用户手里。参考 TokenTracker 的开源思路，叠加 TrustTools 自有能力（安全检测、Skill 市场对接、海报分享）。

## 2. 业务目标

### 主要目标

1. **Token 用量透明化**：让用户看见 token 消耗和费用，按项目/Provider/模型随意下钻
2. **Skill 资产管理**：扫描本地 skill、健康度评估、一键清理、一键同步到多个 AI 工具
3. **Skill 安全检测**：外部下载的 skill 拖进来，静态规则 + AI 审查，几秒出安全报告
4. **记忆聚合**：可配置目录扫描，把散落各 AI 工具的 memory 汇总展示
5. **TrustTools Skill 同步**：打通 Web 端 Skill 库，桌面版直接搜索/下载/安装/版本同步

### 成功信号

- 安装后 2 分钟内看到自己的 token 消耗
- 覆盖 20+ 主流 AI 工具的 token 解析
- 外部 skill → 拖入检测 → 出报告 < 30 秒
- 桌面版搜索 → 选中 → 安装到 Claude/Cursor < 15 秒

### 失败后果

- 覆盖面窄，沦为小众工具
- 隐私策略不当导致用户不信任
- 各模块割裂，体验不统一

## 3. 范围

### 范围内（MVP 6 模块）

| 模块                      | 内容                                                             |
| ----------------------- | -------------------------------------------------------------- |
| **Token 管理**            | 消耗追踪、费用换算（多币种/默认人民币/按各模型官网定价）、项目→Provider→模型多级下钻、用量上限预警、消耗海报生成 |
| **Skill 管理**            | 本地扫描发现、健康度评估（4 级）、一键清理、多 agent 同步安装（Claude/Codex/Grok 等 8 工具）  |
| **Skill 安全检测**          | 拖入/上传 → 静态规则扫描 + AI 代码审查 → 安全报告；每天最多 10 次检测                    |
| **TrustTools Skill 同步** | 搜索 TrustTools Web Skill 库、一键下载安装到指定 agent、版本自动同步检测             |
| **记忆**                  | 可配置目录扫描 + 聚合展示                                                 |
| **桌面客户端**               | macOS + Windows 双平台安装包，托盘常驻、开机自启、嵌入式 Dashboard、多套皮肤/主题切换    |
| **本地浏览器模式**             | 支持一键在本地浏览器打开调试/使用，无需 Electron 壳                              |
| **Node 包分发**             | 发布为 npm 包，支持 `npx` 一键启动，降低安装门槛                              |

### 核心数据维度

```
消耗大盘
  ├─ 时间线：年 → 月 → 周 → 日 → 小时
  ├─ 来源线：Provider → 具体模型 → 单次对话
  ├─ 项目线：项目 → Provider → 模型
  ├─ Token 线：总量 → 输入/输出/缓存读/缓存写/推理 占比
  └─ 费用线：各模型定价 × token 量 = 人民币
```

### Skill 健康度体系

- 4 指标：日均调用频率、最近活跃度、使用趋势、健康状态
- 4 等级：🟢活跃(7天≥5次) → 🟡低频(30天有调用) → 🟠休眠(30-90天) → 🔴废弃(90天+)
- 一键清理 + 垃圾桶机制(5分钟可恢复) + 黑名单

### 范围外

| 内容                    | 原因         | 目标版本 |
| --------------------- | ---------- | ---- |
| 运行时沙箱（Docker）         | 静态检测够用     | V2   |
| 用户自创 Skill 上传到 Web 市场 | 需审核流程，依赖账户 | V2   |
| Chrome 插件             | MVP 最小化    | V1.1 |
| 记忆深度功能（编辑/搜索/标签）      | 先做可配置扫描    | V1.2 |
| 账户体系 / 登录             | 个人版不需要     | V2   |
| 团队功能（消耗看板/Skill 共享）   | 个人版不需要     | V2   |
| 跨设备同步 / 云端备份          | 依赖账户体系     | V2   |
| ccswitch / aipy 集成    | 场景未明       | -    |

### 明确的非目标

- 不是另一个 AI 聊天客户端或 agent
- 不读取/存储用户完整对话内容（仅提取 token 统计元数据）
- 不替代任何现有 AI 工具，而是作为它们之上的"数据主权层"

## 4. 角色与关键场景

### 目标用户

| 角色      | 描述                                   | 优先级 |
| ------- | ------------------------------------ | --- |
| 个人开发者   | 日常使用 3-8 种 AI 编码工具，装了 20-50+ 个 skill | P0  |
| AI 重度用户 | Web + CLI + IDE 多端使用 AI，skill 来源分散   | P0  |

### 核心场景

**场景 1：首次使用**

1. 方式一：下载安装包双击安装；方式二：`npx trusttools` 一键启动
2. 自动检测本地已安装的 AI 工具
3. 打开 Dashboard（桌面窗口或浏览器），看到 token 消耗和费用
4. 扫描本地 skill 目录，查看健康度

**场景 2：Skill 安全检查**

1. 从论坛/群里下载了 skill
2. 拖进客户端安全检测页
3. 静态规则扫描 + AI 代码审查，几秒出安全报告
4. 安全的 → 放心安装；可疑的 → 用户根据风险项自行判断

**场景 3：从 TrustTools 市场安装 Skill**

1. 在桌面版搜索关键词
2. 浏览返回的 Skill 列表（含安全标签、下载量）
3. 选中 Skill → 选择安装到指定 agent
4. 自动下载 + 安检 + 安装，Dashboard 提示完成

**场景 4：消耗海报分享**

1. Dashboard 点「生成海报」
2. 选时间范围、切换视觉模板（暗色/亮色）
3. 预览精美海报 → 保存本地或复制到剪贴板

### 边缘场景

- 用户没有任何 AI 工具（空状态引导）
- 用户离线（本地功能正常，Skill 市场不可用时提示"网络不可用"）
- 用户选了未安装的 agent 作为安装目标（提示并引导安装）
- 安全检测次数用完（提示"今日次数已用完，请明天再试"→ 0:00 自动重置）

## 5. 非功能需求

| 维度             | 需求                                                    | 依据       |
| -------------- | ----------------------------------------------------- | -------- |
| **数据本地化**      | 所有数据存储本地，不上报任何云端                                      | 隐私优先     |
| **启动速度**       | 安装到首次看到数据 < 2 分钟                                      | 用户体验基线   |
| **仪表盘响应**      | 页面加载 < 2 秒，图表渲染 < 1 秒                                 | 用户体验基线   |
| **内存占用**       | 后台进程 < 200MB                                          | 常驻不影响工作  |
| **兼容性**        | macOS 13+ (Apple Silicon + Intel)、Windows 10/11 (x64) | 双平台      |
| **安全与隐私**      | 不读/不存用户完整对话内容，仅 token 统计元数据                           | 隐私红线     |
| **无账号**        | 不需要登录注册，安装即用                                          | 极简上手     |
| **Clean Room** | 架构可借鉴 TokenTracker，代码自研（相似度 < 10%）                    | 合规       |
| **中英文界面**      | 支持中文/英文切换，默认跟随系统语言；数据标签（模型名/Provider名）保留原文               | 覆盖更广用户群 |
| **换肤**         | 至少提供暗色/亮色/高对比度 3 套主题，支持一键切换                        | 个性化与无障碍 |
| **海报设计感**      | 消耗海报需有设计感，至少 2 套视觉模板（暗色/亮色），1080×1920 竖版 PNG，带品牌标识 | 社交传播 |
