## 1. 项目概述

### 背景

业内已有 AI 编码工具 token 用量追踪产品，但缺少安全检测、记忆管理等能力。本产品提供 Token 追踪 + Skill 管理 + 安全检测 + 记忆聚合，打造**个人 AI 主权**桌面工具。

### 产品哲学

> 你的 skills、你的 token 消耗、你的记忆——统一收回，你做主，你掌控。

### 定位声明

个人 AI 工具，开箱即用，无需登录注册。把散落在各 AI 工具的 skills、token 消耗、记忆，统一收回用户手里。

### 利益相关者

| 利益相关者           | 角色    | 关注点            | 影响力 |
| --------------- | ----- | -------------- | --- |
| 老板              | 决策者   | 差异化竞争力         | 高   |
| 产品经理 (liyanjun) | 需求制定者 | 功能范围、用户体验、迭代节奏 | 高   |
| 研发团队            | 实施者   | 工作量、排期         | 中   |
| 目标用户            | 最终使用者 | 安装简单、数据准确、隐私安全 | 高   |

## 2. 目标

### 业务目标

1. **Token 用量透明化**：让用户看见 token 消耗和费用，按项目/Provider/模型随意下钻
2. **Skill 资产管理**：本地 skill 扫描 + 健康度评估 + 一键清理 + 多 agent 同步安装
3. **Skill 安全检测**：外部下载 skill 拖入即扫，10 次/天，几秒出报告
4. **Skill 在线获取**：对接 TrustTools Web Skill 库，桌面端搜索/下载/安装/版本同步
5. **记忆聚合**：可配置目录扫描，把散落各 AI 工具的 memory 汇总展示

### 成功标准

- 安装后 2 分钟内看到 token 消耗数据
- 覆盖 10+ 主流 AI 工具的 token 解析
- 外部 skill 拖入检测 30 秒内出报告
- 安全检测每日上限 10 次，Dashboard 显示剩余次数
- 从 Web Skill 库搜索到安装完成 < 15 秒

## 3. 用户画像

### 画像 1：个人 AI 开发者（P0）

- **特征**：日常使用 3-8 个 AI 编码工具，安装了 20-50+ 个 skill
- **痛点**：不知道花了多少钱、skill 太多不知道哪些没用、下载 skill 怕有安全问题
- **目标**：一个地方看清所有 token 消耗、一键清理废弃 skill、下载 skill 前扫一下

### 画像 2：AI 重度用户（P0）

- **特征**：Web + CLI + IDE 多端使用 AI，安装了大量 skill 来源分散
- **痛点**：各工具的 skill 散落在不同目录，无法统一管理；有些 skill 不知道装到哪个工具了
- **目标**：一个界面管理所有 agent 的 skill、从 TrustTools Web 库一键安装 skill 到指定 agent

## 4. 功能需求

### 4.1 Token 管理

#### FR-001: Token 消耗采集 [MUST]

**描述：** 自动检测并采集本地 AI 工具的 token 消耗数据，无需用户手动操作。

**验收标准：**

- 支持 Claude Code、Codex、Cursor、Gemini CLI、Kimi Code、OpenCode、Grok、GitHub Copilot、Cline、Roo Code、Aipy、WorkBuddy、Windsurf、Antigravity、Kiro、OpenClaw、Every Code、Hermes、CodeBuddy、OMP、Pi、Craft、Kilo CLI、KiloCode、Zed、Goose、Droid、Mimo、ZCode、AnythingLLM 等 20+ 工具
- 首次安装后自动发现已安装的 AI 工具
- 无需用户手动配置各工具的日志路径

**关联史诗：** EPIC-01

---

#### FR-002: 费用换算 [MUST]

**描述：** 将 token 消耗换算为费用，支持多币种切换，默认人民币。

**验收标准：**

- 支持人民币、美元至少 2 种币种
- 按各模型官网公开定价计算
- 用户可在设置中切换币种
- 缓存命中 token 按缓存价格单独计算

**关联史诗：** EPIC-01

---

#### FR-003: 消耗多级下钻 [MUST]

**描述：** 消耗数据可沿多个维度逐级下钻。

**验收标准：**

- 支持 5 条下钻线：时间线（年/月/周/日/小时）、来源线（Provider→模型→对话）、项目线（项目→Provider→模型）、Token 线（输入/输出/缓存读/缓存写/推理）、费用线
- 每级可排序、可筛选
- 明细列表支持分页

**关联史诗：** EPIC-01

---

#### FR-004: 用量预警 [SHOULD]

**描述：** 用户可设置用量/费用上限，超限时 Dashboard 内显示警告。

**验收标准：**

- 支持按日/周/月设置上限
- 支持按总费用或单 Provider 设置
- 超限时 Dashboard 内显示警告
- 预警阈值可配置（如 80%/90%/100%）

**关联史诗：** EPIC-01

---

#### FR-005: Token 消耗海报生成 [SHOULD]

**描述：** 将用户的 token 消耗数据生成一张有设计感的海报，方便分享到社交平台。

**验收标准：**

- 用户可选择时间范围（今日/本周/本月/自定义）
- 海报包含：Token 消耗总量、费用总额、Top 3 Provider 占比、最常用模型、时间范围标注
- 至少提供 2 套视觉模板（暗色/亮色），用户可切换
- 一键生成 PNG 图片（1080×1920 竖版，适配手机分享）
- 支持保存到本地或复制到剪贴板
- 海报底部带 TrustTools 品牌标识

**关联史诗：** EPIC-01

---

### 4.2 Skill 管理

#### FR-006: 本地 Skill 扫描 [MUST]

**描述：** 自动扫描用户设备上各 AI 工具的 skill 目录，汇总展示。

**验收标准：**

- 扫描 Claude Code、Codex、Cursor 等 8 个 agent 的 skill 目录
- 识别每个 skill 的名称、来源、安装时间、最近使用时间
- 新安装 skill 自动识别

**关联史诗：** EPIC-02

---

#### FR-007: Skill 健康度评估 [MUST]

**描述：** 对每个 skill 计算健康度，帮助用户识别哪些该清理。

**验收标准：**

- 4 级健康状态：🟢活跃(7天≥5次) / 🟡低频(30天有调用) / 🟠休眠(30-90天) / 🔴废弃(90天+)
- 每个 skill 展示 4 维度：日均调用频率、最近活跃度、使用趋势、健康状态
- 阈值可配置（默认 90 天废弃线）

**关联史诗：** EPIC-02

---

#### FR-008: 一键清理 [MUST]

**描述：** 支持按健康状态筛选后批量清理 skill。

**验收标准：**

- 支持按健康状态筛选后批量卸载
- 卸载前确认弹窗
- 已卸载的 skill 可在 5 分钟内恢复（垃圾桶机制）
- 支持将 skill 加入黑名单，黑名单 skill 不再出现在扫描结果中

**关联史诗：** EPIC-02

---

#### FR-009: 多 Agent 同步安装 [MUST]

**描述：** 将一个 skill 一键安装到多个 AI 工具的对应目录。

**验收标准：**

- 支持 8 个 agent 目标目录：Claude Code、Codex、Grok、Gemini、OpenCode、Kimi Code、Cursor、Copilot
- 列出所有可用目标，用户勾选安装位置
- 安装成功后展示各目标的安装状态

**关联史诗：** EPIC-02

---

### 4.3 Skill 安全检测

#### FR-010: 文件上传检测 [MUST]

**描述：** 用户上传/拖入 skill 文件，自动运行静态规则扫描 + AI 代码审查。

**验收标准：**

- 支持拖入文件/文件夹、点击上传
- 解包 skill 源码，运行静态规则引擎
- AI 审查作为第二层验证（识别混淆代码、可疑逻辑）
- 生成安全报告：安全/可疑/危险 + 风险项列表
- 风险项包括：恶意 URL/域名、危险命令、硬编码 key/token

**关联史诗：** EPIC-03

---

#### FR-011: 检测次数限制 [MUST]

**描述：** 每日安全检测次数上限 10 次，Dashboard 显示当日剩余次数。

**验收标准：**

- 每自然日最多执行 10 次安全检测
- Dashboard 安全检测页显示"今日剩余 X/10 次"
- 次数用完后提示"今日检测次数已用完，请明天再试"
- 当天 0:00 自动重置计数
- 检测次数存储在本地，卸载重装后归零

**关联史诗：** EPIC-03

---

#### FR-012: 下载前查验 [SHOULD]

**描述：** 用户从 TrustTools Web Skill 库下载 skill 时，自动触发安全检查。

**验收标准：**

- 下载 skill 时自动识别并提示是否先检测
- 检测通过后才允许安装
- 检测失败给出明确风险提示

**关联史诗：** EPIC-03

---

#### FR-013: 安全规则配置 [SHOULD]

**描述：** 用户可配置安全检测规则。

**验收标准：**

- 支持配置恶意 URL/域名规则
- 支持配置危险命令模式
- 支持配置敏感信息检测（硬编码 key/token）
- 规则支持正则表达式

**关联史诗：** EPIC-03

## 7. 用户体验要求

### 关键流程

**流程 1：首次使用**

```
安装（.dmg / 安装包 / 命令行启动）
  → 打开 Dashboard（桌面窗口或浏览器）
    → 自动发现 AI 工具 → 展示 token 消耗
    → 扫描本地 skill → 展示 skill 清单 + 健康度
    → 安全检测页可用（今日剩余 10/10 次）
    → 记忆页可配置
```

**流程 2：Skill 安全检查**

```
安全检测页（显示今日剩余次数）
  → 拖入/上传 skill 文件
    → 扫描中（进度条）→ 次数 -1
      → 安全报告：
        ├── 🟢 安全 → 一键安装
        └── 🟡/🔴 可疑/危险 → 查看风险项，用户决定
```

**流程 3：从 TrustTools Web 库安装 Skill**

```
Skill 市场页 → 搜索关键词
  → 浏览搜索结果（安全标签 + 下载量）
    → 选中 skill → 选择安装目标 agent
      → 自动下载 + 安全检查 + 安装
        → Dashboard 提示安装成功
```

**流程 4：生成海报分享**

```
Dashboard → 点击「生成海报」
  → 选择时间范围 → 切换模板（暗色/亮色）
    → 预览精美海报 → 保存本地或复制到剪贴板
```

### 界面要求

#### UI-001: Dashboard 布局

- 顶部：统计卡片行（今日 Token / 本月费用 / 缓存节省 / 活跃 Skill 数 / 安全检测剩余次数）+「生成海报」按钮
- 中部：消耗趋势图 + 周热力图
- 下部：Provider 分布饼图 + 最近使用模型列表
- 左侧导航：Dashboard / Token 分析 / Skill 管理 / Skill 市场 / 安全检测 / 记忆 / 设置

#### UI-002: Skill 管理双栏布局

- 左栏：Skill 列表（搜索 + 健康状态筛选 + 来源筛选「本地/TrustTools 市场」）
- 右栏：选中 Skill 详情（健康度 4 维度、安装位置、操作按钮）

#### UI-003: 安全检测页

- 顶部：今日剩余次数（"今日剩余 X/10 次"）
- 中部：大块拖入区域（引导文案："拖入 skill 文件开始检测"）+ 点击上传
- 下方：检测历史列表

#### UI-004: 设置页

- 主题切换（暗色/亮色/高对比度）
- 语言切换（中文/英文）
- 监控目录配置
- 预警设置（日/周/月上限，阈值）
- 费用设置（币种切换）
- 健康度阈值（废弃天数等）
- 安全规则配置
- 开机自启开关

## 附录 A：术语表

| 术语                     | 定义                                            |
| ---------------------- | --------------------------------------------- |
| Token                  | AI 模型处理文本的最小单位                                |
| Provider               | AI 模型提供商，如 Anthropic、OpenAI、DeepSeek          |
| Agent/AI 工具            | 用户本地安装的 AI 编码工具，如 Claude Code、Cursor          |
| Skill                  | 一个可复用的 AI 提示词/工具包，以文件形式存储                     |
| 缓存命中 (Cache Hit)       | AI 模型复用之前计算过的结果，计费比原价低                        |
| TrustTools Web Skill 库 | TrustTools V2.4 SkillPackage 提供的公开 Skill 搜索引擎 |
