## 1. 测试策略

### 1.1 质量目标

| 目标             | 标准                                                                              |
| ---------------- | --------------------------------------------------------------------------------- |
| 核心流程不可中断 | 首页大盘加载、Token 数据展示、Skill 扫描、安全检测、会话恢复 5 条关键路径全部通过 |
| 数据准确性       | Token 数、费用换算、环比计算误差 < 1%                                             |
| 本地隐私保证     | 所有功能在断网环境下可正常使用（Skill 市场除外）                                  |
| 空状态体验       | 首次使用、无数据、异常场景均有合理引导，无白屏或崩溃                              |
| 桌面端稳定性     | 托盘、开机自启、主题切换、窗口关闭/恢复行为符合预期                               |

### 1.2 风险清单

| 风险                                      | 等级   | 影响                             |
| ----------------------------------------- | ------ | -------------------------------- |
| R1 27 工具日志格式不一致导致采集失败      | **高** | Token 大盘无数据，核心功能不可用 |
| R2 费用换算错误（单价/货币/环比）         | **高** | 用户对产品信任度下降             |
| R3 安全检测漏检（规则未命中恶意 Skill）   | **高** | 用户安装恶意 Skill，安全风险     |
| R4 Skill 同步冲突处理不当导致数据丢失     | 中     | 用户 Skill 被错误覆盖            |
| R5 网络不可用时 Skill 市场体验差          | 中     | 白屏或无响应                     |
| R6 桌面端托盘/关闭行为违反 macOS 用户习惯 | 中     | 用户困惑、投诉                   |
| R7 本地数据积累超出存储上限               | 中     | 磁盘占满，应用异常               |
| R8 升级安装数据不兼容                     | 低     | 用户数据丢失                     |

### 1.3 测试范围

**覆盖：**

- 6 个模块 32 个 FR 的功能验证
- 空状态、边缘场景、异常处理
- 桌面端交互行为（macOS）
- 数据准确性与隐私合规

**不覆盖：**

- 单元测试 / 代码覆盖率（研发侧负责）
- Windows 平台测试（V1.1 范围外）
- 27 个 AI 工具的逐个日志格式兼容性（研发侧负责）
- 性能压测（研发侧负责）

### 1.4 测试分层

| 层级       | 说明                       | 本文档覆盖                     |
| ---------- | -------------------------- | ------------------------------ |
| E2E 工作流 | 用户完整操作流程           | ✅                             |
| 功能验证   | 单个 FR 的 AC 逐条验证     | ✅                             |
| 边界与异常 | 空状态、错误输入、网络异常 | ✅                             |
| UI 交互    | 导航、主题、响应式         | ✅                             |
| 数据校验   | Token 数、费用、环比准确性 | 部分（需研发提供数据验证工具） |
